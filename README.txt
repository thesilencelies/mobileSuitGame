This project is a board game. The rules of the game are detailed in rules/rules.tex.

The cards are generated by generateCards.py, which creates latex files for each card. Those cards can then be composed into images using generate_card_sheet.py if needed.

The card designs themselves are stored in the csv files, which split the cards by category.


To create the cards:
- Download the image files
- edit generateCards.py at the top to specify the correct file names
- run generateCards.py to create the LaTeX file
then from that LaTeX file you can create a pdf to print
